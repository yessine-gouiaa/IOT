This project is a derivative from the smart-house project
based on ESP32+PlatformIO+website to control it+bunch of control systems

this project have :
-temperature and humidity system to follow the weather and control the fan
-moister sensor to watch sand moisture level and control (water pump) watering system
-light control system that control a heating lamp for sensitive plants
-fire sensor to turn on the water pump in case of fire to save the plant(in case they are expensive one) as much as its possible
etc......
